OTTER Ontology Explorer / Trình khám phá ontology (ontology explorer)

Real lesson graphs from the frozen OTTER ontology. Every item points to a source span in a textbook. Research prototype.

Details

Tap or click a node (or an edge) to see its type, id, support label and source pointers. Drag to pan, wheel or pinch to zoom, drag a node to move it. On a narrow screen, labels appear after you zoom in.

How an executable rule is stored

A rule is stored as one row in table rules (id, subject, grade, rule_type, status, optional formula, support label, strict_executable flag) plus ordered atoms in rule_premises, rule_guards (applicability conditions), rule_conclusions and rule_exceptions. Each atom is (predicate, args, text, negated); args are concept ids. A rule is marked strict_executable = 1 only if it is supported, explicit, has premises and conclusions and no suspected missing guard. (quy tắc thực thi chặt: strict-executable rule)

Atom texts, formulas and variable descriptions are shown only if they pass the verbatim check (at most 25 words, no run of 8 words shared with the evidence spans); otherwise only the stored structure and ids are shown.
